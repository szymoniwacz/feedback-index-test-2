# Scope

The canonical acceptance criteria are in [project requirements](../docs/project-requirements.md).

The first version includes feedback submission, an inbox, manual categorization, category filtering, persistent local data and meaningful tests. Use synthetic feedback only.

Exclude accounts, organizations, voting, comments, attachments, email, analytics, semantic search, automatic AI categorization, LLM calls, microservices and production deployment.

AI is used in the engineering workflow. The application itself does not need AI features.

This bootstrap prepares repository context. Product implementation and task decomposition belong to the subsequent Project Executor demonstration.
